# 回复判断（astrbot_plugin_reply_gate）

让机器人在群里**该接话时接话，不该插嘴时安静**。

AstrBot 内置的「主动回复」是按概率随机插嘴的，经常在别人聊天时冒出来。这个插件接管没有 @ 机器人的群消息，先用名单和规则过滤，再让判断模型（System One）看着前文给这句话打四个分：

| 判断 | 例子 | 机器人怎么做 |
|---|---|---|
| 对机器人说 | 叫了机器人的名字；引用了机器人的消息；机器人刚回答完，对方接着追问 | 回复，不受冷却限制 |
| 对别人说 | 「小红，你吃了吗」；两个人一来一回地聊 | 不插嘴 |
| 对全群说 | 「吃了吗」「有人知道……吗」「大家早上好」 | 按「接话概率」接话，受冷却限制 |
| 新话题 | 冷场后有人说「今天终于发工资了！」 | 同上 |

判断时会参考前几条消息的时间、机器人上次回复的是谁、这句话引用了谁。

## 功能

- **@ 了别人也 @ 了机器人**：比如「@小明，和 @机器人 说句话」，会判断是不是真的对机器人说的（可关闭）。只 @ 机器人的消息照常回复。
- **图片**：判断模型看不到图片，带图的消息会连同图片交给对话模型判断（可关闭，需要选能看图的模型）。
- **退回对话模型**：判断模型超时或不可用时，用你指定的对话模型判断。
- **名字跟着人格走**：机器人的名字取自当前会话的人格，还可以给每个人格加别称。
- **名单**：用户黑名单、群白名单 / 黑名单，可以在面板里点人名直接拉黑。
- **设置面板**：在插件页打开「回复判断」面板，可以调所有设置、查看最近的判断、**试一句话**看模型会怎么判。
- **调试模式**：记录每次判断交给模型的完整输入、四个分数和结论，可在面板查看和导出。

## 安装

1. 在 AstrBot 管理面板的「插件」页选择「从文件安装」，上传本压缩包；或者把 `astrbot_plugin_reply_gate` 文件夹放进 `data/plugins/` 后重启。
2. **关闭 AstrBot 内置的「主动回复」**（配置文件里的 `provider_ltm_settings.active_reply.enable`），否则两边会同时插嘴。插件检测到它开着时会在面板上提醒。
3. 在「模型提供商」里配好一个判断模型（System One）。没有的话也可以只用对话模型判断：关掉「优先使用判断模型」，并选好「退回时使用的对话模型」。
4. 打开「回复判断」面板，确认机器人的名字识别正确，用「试一试」试几句话。

要求 AstrBot 4.29 及以上，不需要额外安装 Python 依赖。

## 主要设置

| 设置 | 默认 | 说明 |
|---|---|---|
| 回复阈值 | 0.5 | 「对机器人说」的分数达到它才回复。调高更安静 |
| 开放问题 / 新话题的判定线 | 0.6 | 「对全群说」或「新话题」的分数达到它，才算可以接的话 |
| 开放问题 / 新话题的接话概率 | 0.5 | 遇到可以接的话时接话的概率，0 表示从不接 |
| 接话冷却（秒） | 30 | 接过一次开放问题 / 新话题后，多久内不再接。对机器人说的话不受限制 |
| 参考的群聊条数 | 8 | 交给模型的前文条数 |
| 自定义判断规则 | 空 | 用自然语言补充规则，例如「别人在讨论工作时不要回应」 |
| 判断失败时仍然回复 | 关 | 模型都不可用时是否照常回复 |

所有设置都能在面板或插件配置页修改，鼠标悬停可看说明。

**机器人话太多**：先调低接话概率，再调高判定线。**机器人太安静**：反过来调，或者调低回复阈值。打开调试模式看看分数卡在哪，再决定调哪个。

## 指令

- `/回复判断`（管理员）：查看最近 10 次判断结果。

## 数据

判断记录、前文和调试记录保存在 AstrBot 的 `data/plugin_data/astrbot_plugin_reply_gate/` 下，不会写进插件目录。调试记录里有群聊原文，分享前请留意。

## 测试
