# 回复判断

AstrBot 插件。群里没有 @ 机器人的消息，由模型判断机器人该不该接话。

## 怎么判断

跳过黑名单里的人和群，以及没提到机器人名字、又太短或只有表情笑声的消息。其余消息连同前几条群聊交给模型，打四个分：

| 分数 | 结果 |
|---|---|
| 对机器人说 | 达到「回复阈值」并且高于「对别人说」时回复 |
| 对别人说 | 达到 0.4 时，不算对全群说或新话题 |
| 对全群说 | 达到「判定线」时，按「接话概率」接话 |
| 新话题 | 同上 |

机器人主动回复一次后，在「接话冷却」时间内不再接「对全群说」和「新话题」。「对机器人说」不受冷却限制。

只 @ 了机器人的消息不经过判断，照常回复。同时 @ 了机器人和别人的消息（如「@小明，和 @机器人 说句话」）会判断是不是对机器人说的。

模型默认用 AstrBot 的判断模型（System One），失败时换用对话模型，都失败时不回复。判断模型看不到图片，所以带图的消息先交给对话模型（可关闭）。

## 安装

1. 在 AstrBot 插件页「从文件安装」，或把本仓库放进 `data/plugins/astrbot_plugin_reply_gate/`。
2. 关闭 AstrBot 内置的「主动回复」（`provider_ltm_settings.active_reply.enable`），否则它会绕过本插件插嘴。
3. 在「模型提供商」里配置判断模型。不配置的话，插件用对话模型判断，默认是当前会话的模型。

需要 AstrBot 4.29 及以上，不需要安装其他依赖。

## 设置

在插件页打开「回复判断」面板修改。常用的几项：

| 设置 | 默认 | 作用 |
|---|---|---|
| 回复阈值 | 0.5 | 调高，机器人更少回应对它说的话 |
| 开放问题 / 新话题的判定线 | 0.6 | 调高，更少的话算作「对全群说」或「新话题」 |
| 开放问题 / 新话题的接话概率 | 0.5 | 遇到可以接的话时接话的概率 |
| 接话冷却 | 30 秒 | 主动回复后多久内不再接 |
| 参考的群聊条数 | 8 | 交给模型的前文条数 |
| 自定义判断规则 | 空 | 用一句话补充规则，如「别人在讨论工作时不要回应」 |

机器人的名字取自当前人格，可以在面板里给人格加别称。用户黑名单和群名单只管主动接话，被 @ 时照常回复。

面板的「试一试」页可以输入一句话，看模型怎么判。调试模式会记录每次判断的模型输入和结果。

管理员指令 `/回复判断` 显示最近 10 次判断。

## 数据

前文、判断记录和调试记录保存在 `data/plugin_data/astrbot_plugin_reply_gate/`，其中有群聊原文。导出或分享调试记录前请检查内容。
